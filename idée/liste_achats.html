1. Déjà dans ton kit Arduino à vérifier

Ces pièces sont dans presque tous les kits de départ. Coche-les quand tu les as trouvées dans ta boîte.

Important pour l'écran LCD : regarde derrière. S'il y a un petit module noir avec seulement 4 broches (GND, VCC, SDA, SCL), c'est bon. S'il a 16 broches, c'est un LCD sans I2C : il faut acheter le module I2C (voir plus bas). C'est peut-être la cause du message « LCD introuvable ».

2. Électronique à acheter

Les éléments avec une bordure dorée sont obligatoires. Les autres, seulement si ton kit ne les a pas.

3. Structure du château

Pour la planche, le mur en pierre lavande, la porte violette avec le cadre doré et les étoiles.
